当前使用 15 类：13 类剧情音效与 2 类 UI 音效；15 条正式时间线包含 64 个动作播放点、17 个环境播放点。

## 播放约定

- `ambience`：环境循环，走 SFX 总线，默认 -8 dB、0.5 秒淡入；进入场景时切换。
- `action`：剧情动作，走 SFX 总线，显式不循环；对应描述推进完毕后停止，时间线入口也会清理，避免长脚步录音跨场景叠加。
- UI 点击：业务按钮与 Dialogic 选项走 UI 总线，仅按下时播放。
- 打字音：每 6 个字符播放一次，走 UI 总线。
- BGM、SFX、UI 音量沿用设置面板的独立滑块。

## 重新导入

在仓库根目录执行：

```powershell
python longe-journey/tools/import_selected_sfx.py 'D:/Downloads/音效选择清单.json' --project-root longe-journey
```

WAV 导入时将整数 PCM / extensible PCM 规范为 16 位 PCM，保留采样率、声道数和帧数；不支持的编码明确报错。MP3 保留原文件。资源路径保持稳定，重新导入不会改变时间线绑定。

回归覆盖：`tests/audio_binding_test.gd`、`tests/ui_audio_test.gd`、`tests/foundation_test.gd`、`tools/tests/test_import_selected_sfx.py`；原剧情序列继续由 `tests/localization_test.gd` 校验。
