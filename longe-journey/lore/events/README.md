# 事件

事件记录已经发生、被玩家亲眼看到的剧情时刻。写剧情前先查这里，避免时间线矛盾。

## 模板

```markdown
# 事件名

- 时间: 游戏内时间或 unknown
- 地点: [地点条目](locations/xxx.md)
- 参与角色: [角色条目](characters/xxx.md)
- 结果: 事件造成的状态变化
- 来源: docs/Dialogic_Implementation_Guide.md 或具体场景/对话
```

## 规则

- 一个事件一个文件，文件名小写英文连字符。
- 时间按游戏流程写，例如 `02_ward`。
- 来源必须能定位到实际内容。
