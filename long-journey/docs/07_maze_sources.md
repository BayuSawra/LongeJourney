# 07_maze 场景摘要

## 使用规则

- 本文件是 `07_maze` 相关工作的高层摘要，后续回合先读本文件；需要细节时再按来源文件定向查行。
- 摘要以 `tools/_twine_extract.txt`、`docs/WORK_PLAN.md` 阶段 4.1、`lore/` 为准；本文件不替代原始文本。
- `tools/_twine_extract.txt` 是原始 Twine 导出的大文件，禁止整读、禁止提交。

## 场景与分支

### 入口（起点 1：`[20] 迷宫`）

- 入口邪风关门，主角自认王爷，出现初始分岔：
  - `往路面宽阔的左边走 -> 迷宫1`
  - `往路面曲折的右边走 -> 迷宫2`

### 露园（起点 2：`[21] 露园`）

- 可输入 `$playerName`；`买票进园（2元）-> 迷宫`（`$money -= 2`）；`回到十字路口 -> 路口`。

### `[22] 迷宫2`（右侧）

- 漏窗偷听：黑衣大氅、灰白长胡子、发髻、蝎纹氅。
- `开始偷听（精力-15，$energy -= 15）`；`继续往前走 -> 迷宫1`。

### `[23] 迷宫1`（左侧）

- 紫袍男人说“前个月那个女的的男人，已经杀了”；两个回应分支最终都进入 `假山迷宫`。

### `[24] 假山迷宫`（中央）

- 画风转恐怖，需要 5 朵花；三个方向：
  - `走左边 -> 左1`
  - `走中间 -> 中1`
  - `走右边 -> 右1`

### `[30] 上1`

- 高处看清迷宫中央华服金钗女人；`往前走 -> 摘绣球花`、`往右走 -> 中2`。

### `[31] 右2`

- 芦荟花盆发现仙人球花；`摘花（精力-5，$energy -= 5）`、`不摘花继续走 -> 摘绣球花`。

### `[32] 摘仙人球花`

- 掉 10 镇定（`$calm -= 10`），`flower += 1`，继续到 `摘绣球花`。

### `[33] 摘绣球花`

- 中央女子眼睛浑浊几乎看不到瞳孔、眼皮细线吊起缝眉、嘴翻动模糊歌声、手无力垂下画符咒；`[[她是怎么立住的？|立住]]`。

### `[34] 立住`

- 棍子从背后穿过衣服，腰带绑棍钉入地面；两个选择：
  - `立刻逃离这里 -> 逃离`
  - `摘下绣球花（镇定-15，$calm -= 15）-> 摘下绣球花`

### `[35] 逃离`

- 狂奔逃出迷宫，皮鞋裂口；`乘车去十字路口（车费2元，$money -= 2）-> 路口`。

### `[36] 摘下绣球花`

- 主角勉强摘下花，`flower += 1`，`离开这里 -> 逃离`。

## Jump 规则

- jump 目标必须是真实 timeline ID 或同文件 label；不要写 Twine 风格 passage 名或中文名（如 `jump 迷宫1`、`jump 左1`）。

## 推荐文件拆分

- `07_maze_entry.dtl`：进入迷宫、第一层岔路
- `07_maze_left.dtl`：左侧分支
- `07_maze_middle.dtl`：中央女人线
- `07_maze_right.dtl`：右侧分支
- `07_maze_exit.dtl`：拿到花/逃离后的收束，最后 `jump 08_wife_room`
- 备选：如迷宫较短，也可用单个 `07_maze.dtl` 配合 Dialogic 内部 label

## 变量维护要点

- `flower`：起始 0，住院部闸口需 `flower >= 5` 放行
- `calm`：摘仙人球花 `-10`，摘绣球花 `-15`
- `energy`：偷听 `-15`，摘仙人球花 `-5`
- `money`：露园买票 `-2`，乘车回十字路口 `-2`
