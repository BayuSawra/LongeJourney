# Lore Schema

条目模板与字段定义。创建或更新 `lore/` 条目时按此结构填写。

## 通用规则

- 每个条目用 Markdown 标题加字段列表；文件名小写连字符。
- 状态值只用：`unknown`、`alive`、`dead`、`missing`、`sealed`、`destroyed`。
- 每条事实尽量标注来源（`timelines/*.dtl`、场景文件、对话）。
- 事实变化时保留旧记录，并在旧值旁加 `superseded_by:`。

## 角色

```markdown
# <角色名>

- 状态: <状态值>
- 首次登场: <来源>
- 当前所在地: <地点条目名或 unknown>
- 年龄/生日: <值或 unknown>
- 身份/职业: <值或 unknown>
- 关系: <角色名> — <关系描述>
- 物品: <物品条目名或 unknown>
- 已知信息:
  - <事实 1>（来源：<来源>）
- 时间线备注: <值或 unknown>
```

## 地点

# <地点名>

## 事件

```markdown
# <事件名>

- 时间: <游戏内时间或 unknown>
- 地点: <地点条目名或 unknown>
- 参与角色: <角色条目名列表>
- 结果: <结果描述>
- 来源: <来源>
```

## 剧情伏笔

`plot-threads.md` 维护所有伏笔：

```markdown
# <伏笔名>

- 状态: open | paid-off | abandoned
- 埋设: <来源/场景>
- 回收: <来源/场景或 unknown>
- 关联角色/地点: <条目名列表>
- 说明: <一段话>
```

## 索引

`INDEX.md` 格式：

```markdown
# Lore Index

## 角色

- <角色名> — <一句话摘要>

## 地点

- <地点名> — <一句话摘要>
```
